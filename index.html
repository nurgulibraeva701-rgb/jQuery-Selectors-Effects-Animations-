What is jQuery?
jQuery is a JavaScript library that makes DOM manipulation, events and animations easier.
What are selectors?
Selectors such as $("#id"), $(".class") and $("tag") are used to find HTML elements.
What are effects?
Effects like hide(), fadeIn() and slideToggle() add simple visual changes to a page.
